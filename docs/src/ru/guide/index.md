# Что такое jrpc-core?

**jrpc-core** — лёгкая Python-библиотека, реализующая [спецификацию JSON-RPC 2.0](https://www.jsonrpc.org/specification) с двумя основными слоями:

| Слой | Модуль | Назначение |
|---|---|---|
| **Сообщения** | `jrpc_core.messages` | Модели Pydantic для запросов, ответов, уведомлений и ошибок |
| **Диспетчер** | `jrpc_core.dispatcher` | Маршрутизация входящих сообщений на обработчики на основе реестра |

## Принципы проектирования

- **Типобезопасность** — каждая модель является `BaseModel` из Pydantic с явными типами полей и валидаторами.
- **Функциональность** — обработка ошибок использует `Result` и `Option` из [pyfplib](https://pypi.org/project/pyfplib/) вместо исключений.
- **Лёгкость** — единственная зависимость от `pydantic` и `pyfplib`, не требует async runtime.
- **Сериализуемость** — чистый обмен между Python-объектами и строками JSON.

## Архитектура

```
Входящая строка JSON
        │
        ▼
   try_parse()
        │
   ┌────┴────┐
   │         │
Запрос  Уведомление
   │         │
   ▼         ▼
JsonRpcDispatcher.__call__()
   │
   ├──► поиск в реестре обработчиков
   │
   ▼
JsonRpcResponse
```
